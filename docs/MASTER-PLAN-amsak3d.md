## 0. كيف تُستخدم هذه الوثيقة

1. اقرأ `docs/NEXT-SESSION.md` أولًا — يحتوي حالة اللحظة والخطوة التالية.
2. اقرأ قسم **القرارات المعمارية (D)** — لا تُخالف أي قرار دون تسجيل سبب.
3. اختر المهمة التالية من **المراحل التنفيذية**، لا من الذاكرة.
4. قبل بدء المهمة: اكتب «بنك أهداف المهمة» (هدف + سبب + اختبار قبل/بعد).
5. بعد إنجازها: شغّل اختبار القبول، ثم أضف سطرًا في **سجل التقدم**.
6. لا تُغلق مرحلة قبل اجتياز **بوابة القبول (Gate)** الخاصة بها.

## 1. الهدف النهائي

تطبيق إمساكية كرار يصبح نسخة أصلية (Kotlin/CMP) مطابقة بصريًا وسلوكيًا لتصميم
`appkarv/amsak3d.tsx`، مع:

- شاشة «اليوم» بالقوس السماوي والطقس والعد التنازلي ومربعات الصلوات.
- 7 وجهات مترابطة عبر **Navigation 3**: اليوم، الضبط والأوقات، التقويم، القبلة
  والمراقد، الأدعية، المسبحة، فقه المواقيت.
- شل **Material 3 Expressive** عائم بالكامل: شريط سفلي عائم، شريط جانبي، شريط
  عنوان عائم بأزرار دائرية منفصلة، وانتقالات انزلاقية مع إيماءات تنبؤية.
- **Edge-to-edge حقيقي** في كل الشاشات: المحتوى يُزاح، والخلفية نفسها تستمر خلف
  شريط الحالة والتنقل والعنوان وأزرار النظام والنوافذ.
- ودجتات سبعة متكيفة + إشعار حي + أذان مخصص يعمل على كل المنصات دون تكرار الصوت.
- بيانات أوقات وتواريخ ومدن أوفلاين مأخوذة من ملف الكفيل، مع DST ذكي لكل تاريخ.
- شاشة بداية أندرويد 12 + شاشة متحركة ثانية مطابقة لـ`Startscreen .txt`.
- بناء Release موقّع ورفعه إلى GitHub Releases وإرساله إلى قناة تلغرام «خاص».

### 6.2 قواعد الزجاج والحركة

- **زجاج**: خلفية `#0b1120` بشفافية 90% + `backdropBlur(24.dp)` + حد `white/10`.
- **ظل الشريط**: `0 10 30 rgba(0,0,0,.60)`.
- **زوايا**: شريط كامل 999dp (كبسولة)، بطاقات 20–28dp، أزرار 999dp.
- **حركة**: `cubic-bezier(0.22, 1, 0.36, 1)` ≈ `CubicBezierEasing(0.22f, 1f, 0.36f, 1f)`،
  مدة 300–650ms، بلا `Crossfade` جذري.
- **الأسطح**: لا كتل مصمتة خلف أشرطة النظام؛ الخلفية الجذرية هي نفسها في كل الشاشات.

### 6.3 الخطوط

- خط عربي أوفلاين واحد أساسي (يُختار من الأصول المتاحة أو يُضمَّن لاحقًا).
- الأرقام والأوقات بخط واضح مع `FontFeatureSettings` إن لزم.
- كل الأحجام من `Typography` المركزي، وتُحترم `fontScale` و`displayScale`.

## 7. مواصفات الشاشات

### 7.1 شاشة «اليوم» (`sky_arc`)

- خلفية تدرج السماء + توهج مركزي + تأثير طقس خفيف.
- الشريط العلوي **غير موجود** في هذه الشاشة (كما في V7 و`amsak3d`).
- القوس: SVG/Canvas بعرض يقارب الشاشة مع هامش 8–12dp، لا يصغر على الشاشات الكبيرة.
- داخله: الساعة الحالية، التاريخ، حالة اليوم، القمر/الشمس حسب الوقت.
- العد التنازلي: يظهر فقط عند وجود صلوات محددة للعدّ؛ وإلا مكان فارغ.
- شريط الصلوات: كبسولات أفقية، الصلاة التالية في المنتصف، وقوس تقدم لكل صلاة.
- الزر السفلي: التقويم فقط، لا ضبط.

### 7.2 شاشة «الضبط والأوقات»

- أقسام منسدلة بعناوين فرعية:
  1. الموقع والمدن (بحث GPS/IP/أوفلاين + صلاحية).
  2. طريقة الحساب ومعايير الكفيل (زوايا، عصر، خطوط عليا).
  3. ضبط الوقت (DST ذكي/صيفي/شتوي + تعديل الدقائق).
  4. الصلوات: إظهار/إخفاء + تذكير + عدّ + أذان (الكل/مسح لكل مجموعة).
  5. الإمساك (تلقائي رمضان/دائم/مخفي).
  6. الودجتات (شاشة فرعية).
  7. الإشعارات والصوت.
- لا مربع بحث مكرر ولا تقويم PDF.
- تنبيه خطوط العرض العليا يظهر هنا فقط.

### 7.3 شاشة «التقويم»

- M3 Expressive: بطاقة شهر واسعة، شبكة أيام، تمييز اليوم.
- تغيير السنة والشهر الهجري والميلادي كلًّا على حدة (سابق/تالي).
- زر دخول مخصص من القوس فقط.
- تظليل أوقات الصلوات والإمساك والإفطار.

### 7.4 شاشة «القبلة والمراقد»

- قرص بوصلة حي مع دوران حسب اتجاه الجهاز.
- قائمة المراقد التسعة من `amsak3d` (الكعبة، المدينة، النجف، كربلاء، الكاظمية،
  مشهد، سامراء، دمشق، قم) مع المسافة والاتجاه واللون.
- صلاحية الموقع مع نافذة نظام وزر تشغيل عند التعطيل.

### 7.5 الأدعية

- قائمة بطاقات واسعة، بلا حد أقصى مصطنع، نص متجاوب.
- كل دعاء في ملف بمعرّف ثابت، مع نص كامل.
- مشغل مناجاة عائم صغير بيضوي: يتوسع/يتقلص، زر دائري، يختفي عند عدم التشغيل،
  ولا يظهر مرتين.

### 7.6 المسبحة

- تصميم من `مسبحة.html`: حلقة تقدم، عدّاد كبير، أهداف (34/33/33)، إحصاءات.
- زر «إضافة تسبيح» / «تسبيح مفتوح» وتغيير الذكر.
- اهتزاز/صوت خفيف اختياري، وحفظ الحالة.

### 7.7 فقه المواقيت

- كل المعايير: طريقة الحساب، زاوية الفجر، زاوية العشاء، مذهب العصر،
  خطوط العرض العليا، تعديل الهجري، تعديل الدقائق، DST.
- شرح مختصر لكل خيار، دون تكرارها في الضبط.

## 11. البيانات والمدن وDST

- `cities.json` الحالي 73,759 مدينة، لكن ~72.5% أسماء لاتينية — يجب تنقية.
- إضافة أسماء عربية للعراق أولًا (المحافظات والمدن الرئيسية)، ثم العالم.

- DST: حساب لكل تاريخ عبر `TimeZone` + قاعدة المنطقة، مع خيار يدوي.
- خوارزمية الأوقات: نقل معايير الكفيل إلى `PrayerEngine` مشترك مع اختبارات ذهبية.
- التقويم الهجري: تعديل `hijriAdjustment`، وعرض الشهرين.

## 12. الصلاحيات والموقع والطقس

- البحث: GPS → أقرب مدينة، أو بحث أوفلاين بالاسم، أو IP كخيار أخير.
