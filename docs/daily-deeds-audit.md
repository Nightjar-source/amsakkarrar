# تدقيق «أعمال اليوم» — مفاتيح الجنان

آخر تحديث: 2026-11-13 (فحص عبر السكربت `audit_dailydeeds.out` ثم حُذفت مخرجات التحليل).

## قاعدة المطابقة

التطبيع: إزالة التشكيل `U+0610-061A, U+064B-065F, U+0670, U+06D6-06ED, U+0640`؛
توحيد `آأإ→ا` و`ى→ي`؛ المقارنة بدون همزات التشكيل.

فئات المطابقة (في `core/jinan/DailyDeeds.kt`):

| # | الفئة | المنطق |
|---|---|---|
| 1 | **أعمال الليلة** (MONTH_NIGHT) | `ليلة/الليلة` + رقم الليلة (صيغة مؤنثة أو مذكرة) — والنصف لليوم 15 |
| 2 | **أعمال اليوم** (MONTH_DAY) | `اليوم/يوم` + رقم اليوم (صيغة مؤنثة أو مذكرة) |
| 3 | **أعمال يوم الأسبوع** (WEEKDAY) | اسم اليوم (الاثنين…الأحد) في العنوان |
| 4 | **أعمال الشهر العامة** (MONTH_GENERAL) | اسم الشهر (كل تهجئاته) بدون رقم صراحةً |
| 5 | **علامات خاصة** (خاص بالشهر+اليوم) | عاشوراء (1/10)، تاسوعا (1/9)، الأربعين (2/20)، المبعث (7/27)، عرفة (9/9)، الغدير (10/18)، دحو الأرض = 25 القعدة (بالرقم)، الثالث عشر والرابع عشر من جمادى الأولى |

الاستبعاد: عنوان يذكر شهرًا آخر → يُستبعد (خاصةً للأشهر الثلاثة الكبيرة: رجب/شعبان/رمضان).
التطابق عبر **`monthNum != null`** يستبعد كل شهر آخر صراحة أو تلميحًا.
